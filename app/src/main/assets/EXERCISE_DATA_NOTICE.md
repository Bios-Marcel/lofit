# Exercise catalog

The bundled exercise metadata and exercise-specific photos are derived from
[`yuhonas/free-exercise-db`](https://github.com/yuhonas/free-exercise-db),
which is released under the Unlicense (public domain).

Images were resized and converted to WebP for offline use in Lofit.
The generic fallback exercise illustration was generated for Lofit.
The band shoulder-rotation illustration was generated for Lofit.
